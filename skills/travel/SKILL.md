# 旅游规划

为用户制定完整的旅游方案时，按以下顺序进行：

## 1. 收集需求

先向用户确认以下信息（缺失的部分要主动询问）：
- 目的地（城市 / 国家，或主题如"海边""古镇"）
- 出行天数
- 出行人数（是否含老人 / 小孩，影响节奏）
- 预算范围（总预算或人均预算）
- 偏好（美食、自然风光、历史文化、购物、亲子、休闲度假等）
- 出行时间（旺季 / 淡季会影响价格和体验）

## 2. 行程规划

- 按天安排行程，每天安排 2-4 个主要景点，避免过于紧凑。
- 同一天内优先安排地理位置相近的景点，减少交通时间。
- 标注景点之间的交通方式和大约耗时。
- 为雨天或体力不支预留 1 个备选室内景点。
- 第一天和最后一天预留办理入住 / 退房和赶交通的时间。

## 3. 预算估算

按以下类别给出估算范围（按人数汇总）：
- 交通：往返大交通 + 市内交通
- 住宿：每晚价格 × 晚数
- 餐饮：早餐 / 正餐 / 小吃
- 门票与活动
- 购物与纪念品（弹性项）
- 应急备用金（建议占总预算的 10%）

## 4. 注意事项

根据目的地给出：
- 证件：身份证 / 护照 / 签证 / 学生证等优惠证件
- 天气：季节气候、衣物建议
- 安全：当地治安、紧急联系电话
- 文化：礼仪禁忌、着装要求（如寺庙、清真寺）
- 实用信息：时差、货币、电压插座、语言

## 5. 输出格式

最终输出一份完整方案，包含：
- **每日行程表**：日期 / 上午 / 下午 / 晚上 / 住宿地点
- **预算清单**：分项预算表
- **打包清单**：按证件、衣物、电子设备、药品、其他分类
- **小贴士**：3-5 条实用建议

除非用户明确要求，否则不要替用户做决定（如选哪个酒店），而是给出 2-3 个选项并说明利弊。
